# Mahesh Ade — Cybersecurity Portfolio

A responsive React + Vite portfolio with a dark, neon-green cybersecurity visual theme.

## Run locally
1. Install Node.js (LTS).
2. Extract this project and open its folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Build
Run `npm run build`. The production site is generated in `dist/`.

## Publish on the internet with Vercel
1. Create a GitHub repository and upload the contents of this folder.
2. Sign in to Vercel using GitHub.
3. Select **Add New → Project**, import this repository.
4. Keep the detected Vite settings (Build Command: `npm run build`; Output Directory: `dist`).
5. Select **Deploy**. Vercel will provide a public URL.
